# שיעורים — תלמוד ירושלמי

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו.

תלמוד ירושלמי, דפוס וילנא (צילום ירושלים תרצ״א, מ-HebrewBooks), בשבעה כרכים — עמודי הגמרא עם פני משה וקרבן העדה, בלי הנספחים. כל עמוד — PNG שחור-לבן ברוחב 1600, ושם הקובץ — מספר העמוד בסריקת המקור.
`yr1/` `yr2/` — זרעים · `yr3/` `yr4/` — מועד · `yr5/` `yr6/` — נשים · `yr7/` — נזיקין ונדה.
